# Small Python Data-Processing App

## Description
This project loads a raw student dataset from a CSV file, cleans the data using Python functions and pandas, and processes numerical data using NumPy.

## Files
- `students.csv` — the raw student dataset.
- `student_data_processing.ipynb` — the Jupyter Notebook for running and explaining the project.
- `student_data_processing.py` — the Python script containing the processing functions.
- `requirements.txt` — the required Python packages.

## Requirements
- Python
- NumPy
- pandas
- Jupyter Notebook
- ipykernel

## Setup
Install the required packages using:

```bash
python -m pip install -r requirements.txt
```

## Run
Open the Jupyter Notebook and run the cells in order.
